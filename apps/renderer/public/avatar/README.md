# 아바타 자산 (PNG)

이 폴더에 다음 5개 PNG를 넣으면 즉시 반영됩니다 (코드 변경 불필요).

## 파일

| 파일명 | 상태 | 자세 가이드 |
|---|---|---|
| `idle.png` | 대기 중 (필수) | 앉아서 차분, 눈 살짝 감음 |
| `attentive.png` | 호명 직후 | 귀 쫑긋, 눈 또렷, 살짝 든 자세 (없으면 `idle.png` 폴백) |
| `listening.png` | 듣는 중 | 귀 한쪽 기울임, 호기심 |
| `thinking.png` | LLM 처리 중 | 고개 갸웃, 발 들기 |
| `speaking.png` | 말하는 중 | 입 살짝 벌림, 활발 |

## 기술 스펙

- 정사각형 PNG, **투명 배경**
- 권장 해상도: **288×288** (디스플레이 120px의 2배, retina 대응)
- 캐릭터가 frame 95% 채우게 — 둥근 마스크가 적용되어 모서리는 잘림
- 세로 꼬리/귀가 잘릴 수 있으니 살짝 안쪽으로

## 추천 AI 생성 프롬프트 (ChatGPT + DALL-E 3)

ChatGPT에 다음을 붙여 넣고 5장 batch 요청:

```
같은 검은 고양이 캐릭터를 5가지 자세로 그려줘. 모두 같은 스타일/같은 캐릭터로 일관성 유지.

공통 스타일:
- chibi 스타일 작은 고양이 (얼굴 크고 몸 작음)
- flat soft cartoon, simple clean lines
- 노란 동그란 눈
- 단색 배경(흰색 또는 투명) — 그림자 없음
- 전신, 정면 또는 살짝 비스듬, 캐릭터 1마리만 가운데
- 정사각형 프레임

5가지 자세 (각각 1장씩):
1. idle: 차분히 앉아서 눈 반쯤 감음, 졸린 듯
2. attentive: 귀 쫑긋, 눈 또렷, 고개 살짝 든 채 정면
3. listening: 고개를 한쪽으로 기울임, 한쪽 귀 살짝 앞으로
4. thinking: 고개 갸웃하고 앞발 하나 들어 턱 옆에
5. speaking: 입 살짝 벌리고 표정 활발, 꼬리 들림

각 자세에 맞는 표정 명확히. 같은 색감/같은 비율 유지.
```

생성 후:
1. 5장 다운로드
2. 배경이 흰색이면 [removebg.com](https://www.remove.bg/) 같은 도구로 투명 처리
3. 파일명을 위 표대로 변경
4. 이 폴더에 드롭 → 앱 새로고침

다른 모델 (Midjourney/SDXL) 써도 됨. 같은 캐릭터 5포즈 일관성이 핵심.
