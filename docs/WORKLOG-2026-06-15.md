## 핵심 설계 결정 (D-013)
- **단일 클라우드 두뇌**: 같은 `pa-core`를 Linux로 빌드해 Fly(도쿄)에서 구동. 텔레그램 봇·데스크톱이 클라이언트. 두뇌 복제 금지.
- **멀티테넌트 격리 = 공유 Core + 전 테이블 `user_id`**. DB 비어 있을 때 도입해 retrofit 비용 0.
- **쓰기 실행을 Core로 이관** → 클라이언트는 승인만(`approved`), 매핑 중복 소멸.
- **게이트웨이 = 공개 TLS + 강한 토큰**(v0). Tailscale 사설망은 후속 강화안.
- **폰 대화 = 데이터 공유 + 채팅 스레드 분리**: `user_id=1`로 todos·메모리·캘린더 공유, 채팅 로그만 `conversation_id="tg:<chatId>"`로 분리.
