# UI 도메인 문서

`apps/renderer`(React UI) + `apps/main`의 창/표시 동작에 대한 **현재 상태·불변식·gotcha·열린 이슈**.
why(결정 맥락)는 `docs/DECISIONS.md`, 시간순 변경은 `docs/worklog/`.

> 작업 전 이 폴더에서 해당 문서를 읽고, 작업 후 **바뀐 불변식이 있으면 같은 커밋에서 갱신**한다.
> 빈 스텁 문서는 만들지 않는다 — 지식이 쌓인 주제만 문서화하고, 그 전까진 아래 "예정"에 1줄로 둔다.

## 타이포·밀도 규칙

좁은 패널(520px) 안에서의 글씨 크기 스케일. **읽는 텍스트는 12px 밑으로 내리지 않는다.**

| 용도 | 클래스 | px |
|---|---|---|
| 헤더 탭(상단바) | `text-sm` + `font-medium`/`font-semibold` | 14 |
| 섹션 제목 | `text-sm font-semibold` | 14 |
| 본문·라벨·버튼·인풋·서브탭 | `text-xs` | 12 |
| **메타(예외)** | `text-[10.5px]` ~ `text-[11px]` | 10.5~11 |

- 컨테이너 기본은 `text-sm`(14px). 그보다 작게 줄일 땐 **읽는 텍스트는 `text-xs`(12px)까지만**.
- 읽기 텍스트 가독성 우선. 글씨를 키워 스크롤이 늘면 간격(`gap`/`py`)으로 조정한다.

### 메타 예외 (2026-08-31 개정)

원래는 `sub-12px 금지`가 전면 금지였다. 2026-06-19에 상단바·설정 글씨가 너무 작아 전부
12px 이상으로 올리면서 생긴 규칙인데, **읽는 텍스트와 곁다리 정보를 구분하지 않은 게 과했다.**
본문이 14px인데 타임스탬프도 12px이면 크기 차이가 거의 없어 "뒤로 물러난" 느낌이 사라진다.

**메타 = 한 번 스치고 마는 곁다리 정보.** 이것만 10.5~11px을 허용한다:

- 타임스탬프(`08:02`), 날짜 구분선 라벨
- 카운트 배지(`3건`), D-day 칩 같은 짧은 상태 표시
- 키보드 힌트(`⏎ 전송 · ⇧⏎ 줄바꿈`), 보조 액션 버튼(`비우기`)

**메타가 아닌 것** — 안내 문구, 설명, 에러 메시지, 빈 상태 문구, 입력 placeholder.
사용자가 **읽어서 뜻을 파악해야 하는 것**은 전부 12px 이상이다. 애매하면 12px로 둔다.
