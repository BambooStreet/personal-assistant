# 리디자인 실행 계획

외부 디자이너 핸드오프(Mucha/Art Nouveau — 라이트 "Parchment" / 다크 "Nocturne")를
코드에 반영하는 순서와, 그 과정에서 정한 것들. 핸드오프 원본은
`design/design_handoff_miya_personal_panel/`, 다음 요청서는 [HANDOFF-REQUEST.md](HANDOFF-REQUEST.md).

## 진행 상황

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 팔레트·폰트·패널 껍데기 (기능 변경 0) | ✅ 반영 |
| 2 | 채팅 화면 리스타일 | ✅ 반영 |
| 3-1 | 개인 탭 → 일정·할 일·목표 3탭 분리 | ✅ 반영 |
| 3-2 | 목표 탭 세부 (이유·이정표·꾸준한 노력) | ✅ 반영 [D-026] |
| 3-3 | 일정 탭 세부 (월간 캘린더) | ✅ 반영 (`calendar.range` 추가) |
| 3-4 | 할 일 탭 세부 (난이도·연결 목표·트리거) | ✅ 반영 (마이그레이션 0013·0014) |
| 3-5 | 루틴 트리거 전환 | ⏸️ **남은 마지막 — 배포된 알림을 건드린다** |

3-2~3-4를 하며 UI가 팝업 중심으로 바뀌었다(`common/Modal`). 할 일 행에서
체크박스를 걷어내고 호버 아이콘 둘(수정 / 완료·되돌리기)로 정리했으며, 삭제는
편집 폼 안으로 옮겼다. 목표 상세의 '꾸준한 노력'은 연결된 할 일 뷰가 됐다.

2단계에서 **설정·비용은 손대지 않았다** — 시안이 없고, 어차피 세부를 다시 다듬을 화면이라
지금 팔레트가 적용된 상태로 둔다. **할 일 화면도 건너뛰었다** — 시안이 난이도·연결 목표·트리거
같은 새 필드를 전제해서 룩만 떼어내기 어렵고, 3단계에서 어차피 다시 만든다.

### 2단계에 들어간 것 (채팅)

- 어시스턴트 아바타(28px 골드 링 + 디스플레이 이니셜) + 이름/시각 행. 카드는 아바타 폭만큼
  들여써 버블과 왼쪽을 맞춘다.
- 말풍선 꼬리를 radius로(어시스턴트 좌상단 2px / 유저 우상단 2px), 유저는 accent 단색.
  그라디언트(`.accent-gradient`)와 `--accent-grad-*`는 쓰는 곳이 없어져 제거.
- 날짜 구분선(양옆 골드 그라데이션), 타이핑 인디케이터(골드 점 dotPulse),
  카드·컴포저 안쪽 3px 골드 헤어라인, 타이틀바 `bg-sidebar`.
- Cinzel + 나눔명조 번들. 한글은 Cinzel에 글자가 없어 명조로 떨어진다(의도된 폴백).
- ⚠️ 타이틀바에 배경이 생기면서 `panel-card`에 `overflow-hidden`이 필요해졌다 —
  없으면 헤더 배경이 둥근 모서리 밖으로 삐져나온다.

**제외한 것**(기능이지 스타일이 아니다): 퀵 리플라이 칩, 메시지 액션(복사·다시 생성·도움됨),
읽음 표시, 슬래시 명령. 특히 슬래시 명령은 동작하지 않는데 안내만 띄우면 거짓말이 된다.

### 1단계에 들어간 것

- 팔레트 전면 교체(인디고 → 브론즈/골드). 원본은 라이트=`:root`/다크=`.dark`인데 우리는
  반대라 뒤집어 옮겼다. **원본 `--primary`가 우리 `--accent`**다(원본 `--accent`는 버디그리
  → 우리 `--teal`). 이름만 보고 옮기면 주요 버튼이 전부 청록이 된다.
- `border-white/x` 96곳 → `border-line`/`bg-hairline`. 라이트에서 테두리가 안 보이던 문제로,
  `--line` 토큰이 애초에 그것 때문에 있었는데 안 쓰이고 있었다.
- 유저 말풍선·전송 버튼 `text-white` → `text-accent-fg`. 다크 accent가 밝은 골드라 흰 글씨면
  대비 1.7:1이 된다.
- 패널 안쪽 5px 골드 헤어라인(이중 프레임)을 `::before`로. `border`로 그리면 헤더 드래그
  영역이 1px 밀려 창을 못 끄는 버그가 된다.

## 정한 것

### 폰트 — 디자이너 안 수용 (2026-08-31)

한때 고운돋움(제목·라벨)으로 갔다가 되돌렸다. 이유는 **굵기가 400 하나뿐**이라
디자이너 스펙(큰 제목 19px/700, 섹션 라벨 11px/600, 탭 12.5px/500·600)을 낼 수 없어서다.
가짜 볼드는 라운드 산세리프에서 뭉개진다.

지금은 **Inter(라틴) + Noto Sans KR(한글)**, 둘 다 **variable**로 번들한다.

- variable을 고른 이유: Noto Sans KR은 정적 굵기로 받으면 한글 서브셋이 굵기당 ~540KB라
  400/500/600/700 네 벌이면 2.2MB를 **전부** 로드한다. variable은 축 하나로 커버하고
  유니코드 범위별로 쪼개져 있어 화면에 실제로 뜬 글자 범위만 받는다.
- 디스크 3.9MB(131개 woff2)를 설치본에 넣지만 런타임 로드는 그 일부다.
- **CDN 금지** — 설치본이 `file://`로 뜨므로 Google Fonts 링크는 오프라인에서 폰트가 통째로
  사라진다. 전부 번들해야 한다.
- Cinzel + 나눔명조는 2단계(채팅)에서 추가했다. 아직 안 넣은 것은 Noto Serif KR(목표 '이유')뿐 —
  해당 화면을 만들 때 추가한다.

### 루틴: 요일+시각 → 트리거 + 생활 프로필 매핑 (방향 결정, 미구현)

디자인이 [D-021]의 루틴 모델과 정면으로 부딪힌다.

| | |
|---|---|
| 현재(D-021, 배포됨) | `goal_routines` = 요일 비트마스크 + **시각 한 점** → 그 시각에 OS 알림 |
| 디자인 | **빈도 개념 없음**, 매일 전제. `cycle` = **트리거**(일어나자마자 / 아침 / 이동 간 / 점심 후 / 저녁 / 자기 전 / 틈틈이) |

시각이 사라지면 알림을 언제 쏠지가 사라진다. **트리거를 생활 프로필 시각에 매핑하는 방향으로
간다** — `lifestyle.wake_weekday` / `sleep_weekday` / `blocks` 설정이 이미 있으므로
"일어나자마자"→기상 시각, "자기 전"→취침 시각, "점심 후"→해당 블록 끝처럼 풀 수 있다.
사용자가 "22:00"을 직접 치는 것보다 생활 리듬에 붙는 게 낫다는 판단.

구현 전에 정해야 할 것:
- "틈틈이"·"이동 간"처럼 **시각으로 환원되지 않는 트리거**를 알림에서 어떻게 다룰지
  (알림 없이 목록에만 두는 선택지 포함).
- 생활 프로필이 비어 있을 때의 폴백.
- 기존 `goal_routines`(요일+시각) 행의 마이그레이션 — 버릴지, 트리거로 근사할지.
- 이건 [D-021]의 일부를 뒤집으므로 구현 시 새 D-번호가 필요하다.

### 이정표(마일스톤) — 반영됨 [D-026]

[D-021]의 "진척률·마일스톤 의도적 미구현"을 뒤집었다. 근거와 설계 판단(진행률을 저장하지 않는
이유, 편집 저장을 통째 교체가 아니라 id reconcile로 한 이유, 체크를 별도 경로로 뺀 이유)은
`docs/DECISIONS.md`의 D-026에 있다.

산길 SVG는 **경로와 채움만** SVG이고 노드·라벨은 절대배치한 HTML이다 — 한글 라벨의 nowrap·
말줄임·알약 배경을 SVG `<text>`로 계산하는 것보다 훨씬 안정적이고, 노드를 진짜 버튼으로
만들 수 있다. 폭은 ResizeObserver로 재서 픽셀로 계산한다(viewBox를 늘려 맞추면 원이 타원이 된다).
