## 복붙 블록 (여기부터 끝까지 복사)

너는 데스크톱 **위젯형 AI 비서 앱**의 디자인 시스템을 설계한다. 지금은 개별 화면이 아니라,
모든 화면에 반복되는 **공통 시각 언어(팔레트 + 프리미티브 컴포넌트)**를 라이트/다크 양쪽으로 확정하는 게 목표다.

### 제품/환경 제약 (반드시 지킬 것)
- **작은 데스크톱 위젯**이다. 패널 폭 ~360px, 세로로 길고 내부 스크롤. 밀도 높고 컴팩트하게(작은 폰트·좁은 여백).
- **프레임리스 창**. 상단 헤더가 창 드래그 영역, 모서리는 16px 라운드.
- 스택: **React + Tailwind (utility class 전용)**, 아이콘 **lucide-react**. CSS-in-JS / CSS Modules / shadcn 금지.
- **라이트/다크 두 모드 모두** 설계. 다크가 기본. 색은 아래 **시맨틱 토큰 이름**으로만 참조(하드코딩 hex 금지).
- 폰트: Pretendard (한국어 UI).

### 시맨틱 토큰 (이 이름들만 사용. 값은 네가 라이트/다크로 설계)
색은 `rgb(var(--토큰) / <불투명도>)` 형태로 쓰인다. 즉 각 토큰은 **"R G B" 채널 3개**로 정의된다.

| 토큰 | 용도 | 현재 다크값(R G B) | 라이트값 |
|------|------|------------------|----------|
| `--bg` | 앱 최하단/패널 본체 배경 | `18 18 22` | ← 설계 |
| `--bg-panel` | 중간 표면 | `28 28 34` | ← 설계 |
| `--bg-elevated` | 카드·버튼·활성 탭 배경 | `38 38 46` | ← 설계 |
| `--fg` | 기본 텍스트 | `245 245 248` | ← 설계 |
| `--fg-muted` | 보조 텍스트 | `160 160 170` | ← 설계 |
| `--fg-subtle` | 약한 텍스트·placeholder | `110 110 120` | ← 설계 |
| `--accent` | 강조·주요 버튼·포커스 | `120 170 255` | ← 설계 |
| `--hairline` | 얇은 테두리·구분선·스크롤바의 "채널" | `255 255 255`(흰색, 저불투명도로 사용) | ← 설계(라이트는 어두운 채널로) |

- 다크값은 그대로 둬도 되고, 더 낫게 다듬어 제안해도 된다.
- **라이트 팔레트가 핵심 산출물**이다. 순백(255)만 쓰지 말고 미묘한 회색 계조로 층을 만들어라(--bg / --bg-panel / --bg-elevated가 라이트에서도 구분되게).
- 상태색(에러=빨강, 경고=앰버, 성공=초록)은 Tailwind 기본 팔레트를 쓰되, 라이트/다크에서 대비가 충분한 톤을 지정만 해줘도 된다.

### 설계할 프리미티브 (현재 다크 마크업 = 구조·클래스 참고용. 룩은 네가 개선)
아래 요소들을 **라이트·다크 나란히** 보여주는 하나의 쇼케이스 화면으로 만들어라.

1. **패널 껍데기(카드)** — 16px 라운드, `bg-bg` 배경, 은은한 그림자 + 1px hairline 링. 상단 드래그 헤더(높이 ~36px) + 하단 콘텐츠.
2. **탭 바** — 헤더 안 텍스트 탭들(채팅/할일/비용/설정). 활성: `bg-bg-elevated text-fg`, 비활성: `text-fg-muted` + hover. 우측에 최소화/닫기 아이콘 버튼.
3. **섹션 카드** — 현재: `rounded-md border border-white/5 bg-bg-elevated/60 p-2.5`. 설정 화면의 기본 블록. 제목(text-sm font-medium) + 설명(text-xs text-fg-subtle).
4. **주요 버튼** — 현재: `rounded-md bg-accent/80 px-2.5 py-1 text-xs font-medium text-bg`, disabled는 opacity-50.
5. **보조/고스트 버튼** — 현재: `border border-white/10 text-fg-muted hover:bg-bg-elevated`.
6. **아이콘 버튼** — 28×28, `text-fg-muted hover:bg-bg-elevated hover:text-fg`.
7. **텍스트 입력** — 현재: `rounded-md border border-white/10 bg-bg/60 px-2 py-1 text-xs`, focus시 `border-accent/60`.
8. **토글 스위치** — 24×44 pill, on=`bg-accent/80`, off=`bg-bg/60`, 링 `ring-white/10`, knob 20×20 `bg-fg`.
9. **세그먼트 컨트롤** — (예: 라이트/다크 선택) `bg-bg/60 p-0.5 ring-white/10`, 활성 세그먼트 `bg-accent/80 text-bg`.
10. **상태 배너** — 경고(앰버)·에러(빨강) 두 변형. `border + bg/10 + text/200`.
11. **빈 상태 / 에러 상태** — 리스트가 비었을 때, 요청 실패했을 때의 소박한 표시(아이콘 + 한 줄).
12. **얇은 스크롤바** — 4px 알약, hairline 톤.

> ⚠️ 중요: 현재 테두리·구분선은 흰색 저불투명도(`border-white/5`, `ring-white/10`)로 되어 있어 **라이트 모드에서 안 보인다.**
> 네 설계에서 라이트/다크 각각의 **테두리·구분선 톤**을 명시해줘(우린 이걸 `--hairline` 토큰으로 배선한다).

### 산출물 형식 (이렇게 줘)
1. 위 프리미티브 전부를 **라이트·다크 나란히** 보여주는 **React + Tailwind 단일 컴포넌트**.
2. 맨 위(또는 별도 코드블록)에 **팔레트 CSS 변수** 두 벌 — 아래 형식 그대로, 채널은 공백 구분 "R G B":
   ```css
   :root {           /* 다크 (기본) */
     --bg: 18 18 22;
     --bg-panel: ...;
     --bg-elevated: ...;
     --fg: ...;
     --fg-muted: ...;
     --fg-subtle: ...;
     --accent: ...;
     --hairline: ...;
   }
   .light {          /* 라이트 */
     --bg: ...;
     ... (동일 키 전부)
   }
   ```
3. 색은 반드시 `bg-bg`, `text-fg-muted`, `bg-accent`, `border-*`처럼 **토큰 기반 유틸리티**로. 하드코딩 hex/rgb 금지.
4. 라운드는 카드=16px, 그 외 요소=6~8px 수준으로 통일.

(복붙 블록 끝)

## 결과 받은 뒤 (이 세션에서 처리)
- 받은 `:root`/`.light` 팔레트 → `apps/renderer/src/styles/globals.css`에 교체.
- hairline/테두리 톤 → `--hairline` 및 필요시 `border-line` 토큰으로 배선(`border-white/x` 정리).
- 프리미티브 스타일 차이 → 해당 컴포넌트(SettingsPage의 카드/토글/버튼, BottomPanel 껍데기 등)에 반영.
- 검증: `npm run typecheck` + 실행(`npm run dev`)해서 라이트/다크 토글로 눈 확인.
