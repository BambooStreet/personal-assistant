# 작업 기록 — 2026-08-08

## 라이트/다크 테마 + 채팅 UI 리디자인 (feat/theme-light-dark)

### 무엇을·왜
- 기존 다크 전용 UI에 **라이트/다크 모드**를 도입. 화면마다 화이트 버전을 손으로 만드는 대신,
  색을 **시맨틱 토큰(CSS 변수)** 으로 돌려 토큰 값만 스왑하면 전 화면이 따라오게 설계(무회귀: 다크=현행).
- 이어서 Claude 디자인이 뽑은 **채팅 리디자인**(인디고 accent)을 1단계 "순수 리스타일"로 반영 —
  기능·데이터·배치는 그대로, 버블·입력창 룩만.

### 변경 요약
- **Core** (`8dfd0c1`): `settings.rs` allowlist에 `ui.theme` 키 추가. 새 IPC 메서드 없이 기존
  범용 `settings.get/set` 재사용(4곳 확장 불필요).
- **Renderer** (`b3082b0`):
  - `tailwind.config.ts`: `bg/fg/accent` → `rgb(var(--x)/<alpha>)` 토큰화, `line` 색 추가.
  - `globals.css`: `:root`(다크)/`.light` 팔레트 두 벌 + `--line`/`--hairline`/`--accent-grad-*`,
    `.accent-gradient` 유틸. 스크롤바 흰색 하드코딩도 `--hairline`로.
  - `useUserSettingsStore`: `theme` 상태 + `setTheme`(Core 저장 + `ui.themeChanged` broadcast) + `applyThemeLocal`.
  - `useTheme.ts`(신규): `<html>.light` 토글 + 창 간 broadcast 수신(아바타/패널 동기화).
  - `SettingsPage`: 일반 탭에 라이트/다크 세그먼트 토글.
  - 채팅 `MessageBubble`/`ChatInput`: 인디고 그라디언트 유저 버블, 실선 테두리 어시스턴트 카드,
    라운드 입력 카드 + 그라디언트 전송 버튼. 마크다운 색은 버블색 상속(양 모드 대비).
- **Docs**: `docs/design/THEME-HANDOFF-KIT.md` — Claude 디자인용 복붙 브리프(시맨틱 토큰·프리미티브).

### 미해결 / 후속
- **테마 저장의 테넌시**: 현재 단일 유저 전제(추후 per-user). [[project_cloud_brain_tenancy]] 참고.
- **2단계(새 요소)**: 인챗 일정/할일 카드, 메시지 액션(복사/다시생성/도움됨), 빠른답장 칩,
  어시스턴트 아바타 칩·타임스탬프 — 데이터 배선 필요, 별도 진행.
- **다른 화면 하드코딩 정리**: Todo·설정 등의 `border-white/x` 흰색 오버레이는 라이트에서 흐릿 →
  `border-line` 계열로 순차 정리 예정.
- `border-line`은 Tailwind config 신규 색이라, dev 라이브에서 config 미반영 시 재시작 필요할 수 있음.
