## 발단 — 외부 디자이너 시안 도착

UI 리디자인을 외부 디자이너와 진행했고 인터랙티브 목업(Mucha/Art Nouveau 계열, 라이트
"Parchment" / 다크 "Nocturne")을 받았다. 1차(8/30) → 요청서 전달 → 2차(8/31) 두 번에 걸쳐
받았고, 그중 **팔레트·폰트·채팅 화면까지** 코드에 반영했다.

핸드오프 품질은 좋았다 — 토큰 파일 분리, 라이트/다크 양쪽, 대비 검증, 상태·애니메이션 값,
"CJK 칩에 nowrap 필수" 같은 실전 함정까지. 힘들었던 건 디자인이 아니라 **이름 체계 매핑**과
**스코프가 섞여 있는 것**이었다.

## 반영 — 1단계(팔레트·껍데기)

- 인디고 → 브론즈/골드 전면 교체. 원본이 라이트=`:root`/다크=`.dark`인데 우리는 반대라
  방향을 뒤집어 옮겼다.
- **가장 위험했던 지점**: 원본 `--primary`(브론즈)가 우리 `--accent`이고, 원본 `--accent`는
  버디그리라 우리 `--teal`이다. **이름이 같은데 의미가 반대**라 그대로 옮겼으면 주요 버튼이
  전부 청록색이 됐을 것이다.
- `border-white/x` 96곳을 `border-line`/`bg-hairline`으로. 라이트에서 테두리가 안 보이던
  문제였고 `--line` 토큰이 애초에 그것 때문에 있었는데 정작 안 쓰이고 있었다.
- 유저 말풍선 `text-white` → `text-accent-fg`. 새 다크 팔레트의 accent가 밝은 골드라
  흰 글씨면 대비 1.7:1이 된다.
- 패널 안쪽 5px 골드 헤어라인(이중 프레임)을 `::before`로. `border`로 그리면 헤더 드래그
  영역이 1px 밀려 창을 못 끄는 버그가 된다.
- 창을 660×960으로 키웠다가 실사용에서 너무 커서 **520×680으로 되돌렸다**. 디자이너도
  520 기준으로 다시 그렸다(2차에서 "최종 스펙"으로 확정).

## 반영 — 폰트

한때 고운돋움으로 갔다가 되돌렸다. **굵기가 400 하나뿐**이라 디자이너 스펙(제목 19px/700,
라벨 11px/600, 탭 500·600)을 낼 수 없었고, 가짜 볼드는 라운드 산세리프에서 뭉개진다.

지금은 **Inter + Noto Sans KR**, 둘 다 **variable**이다. 정적 굵기로 받으면 Noto Sans KR
한글 서브셋이 굵기당 ~540KB라 네 벌이면 2.2MB를 전부 로드하는데, variable은 축 하나로 커버하고
유니코드 범위별로 쪼개져 있어 화면에 실제로 뜬 범위만 받는다. 채팅 디스플레이용 Cinzel +
나눔명조도 추가했다(Cinzel엔 한글이 없어 한글은 명조로 떨어지는데 의도된 폴백).

**CDN은 못 쓴다** — 설치본이 `file://`로 뜨므로 Google Fonts 링크는 오프라인에서 폰트가
통째로 사라진다.

## 반영 — 2단계(채팅 리스타일)

어시스턴트 아바타(골드 링 + 이니셜) + 이름/시각 행, 말풍선 꼬리를 radius로, 날짜 구분선
골드 그라데이션, 타이핑 인디케이터를 골드 점 dotPulse로, 카드·컴포저에 안쪽 골드 헤어라인,
타이틀바 `bg-sidebar`.

부수 효과 하나: 타이틀바에 배경이 생기면서 `panel-card`에 **`overflow-hidden`이 필요**해졌다.
없으면 헤더 배경이 둥근 모서리 밖으로 삐져나온다.

**기능은 넣지 않았다** — 퀵 리플라이 칩, 메시지 액션(복사·다시 생성·도움됨), 읽음 표시,
슬래시 명령. 특히 슬래시 명령은 동작하지 않는데 안내만 띄우면 거짓말이 된다.

## 타이포 규칙 개정

`sub-12px 전면 금지`를 고쳤다. 2026-06-19에 상단바·설정 글씨가 작아 전부 올리며 생긴
규칙인데 **읽는 텍스트와 곁다리 정보를 구분하지 않은 게 과했다** — 본문이 14px인데 타임스탬프도
12px이면 크기 차이가 없어 "뒤로 물러난" 느낌이 사라진다.

읽는 텍스트는 12px 유지, **메타만 10.5~11px 허용**. 메타 = 타임스탬프·날짜 라벨·카운트 배지·
키보드 힌트처럼 한 번 스치고 마는 것. 안내·설명·에러·빈 상태·placeholder는 메타가 아니다.
경계를 `docs/UI/README.md`에 적어놨다.

## 검증

전 워크스페이스 typecheck, 렌더러 vitest 38개, 렌더러 빌드 통과. 마크업을 검증하는 테스트
2개(DateDivider 선, MessageBubble 점)는 새 스타일에 맞춰 갱신했다.
실제 앱으로 팔레트·폰트·채팅 화면을 눈으로 확인했다.

## 미해결 / 후속

- **설정·비용 화면은 손대지 않았다.** 시안이 없고, 어차피 세부를 다시 다듬을 화면이라 지금
  팔레트만 적용된 상태로 뒀다.
- **할 일 화면도 건너뛰었다.** 시안이 난이도·연결 목표·트리거 같은 새 필드를 전제해서 룩만
  떼어내기 어렵다 — 3단계에서 다시 만든다.
- **3단계는 기능 추가라 설계가 필요하다.** 개인 탭 → 일정/할 일/목표 3탭 분리, 월간 캘린더,
  목표 이정표(=[D-021]이 의도적으로 미구현한 것), 루틴을 요일+시각에서 트리거+생활 프로필
  매핑으로 전환. 마이그레이션 + IPC + Core 로직이 붙는다.
- **디자인 최종 룩은 코드 쪽에서 못 봤다.** `.dc.html`이 Claude Design 런타임을 요구하는데
  번들에 없어 브라우저로 열면 템플릿 바인딩이 그대로 보인다. 스펙이 상세해 구현은 됐지만
  룩 대조는 못 했다.
- **아바타 창(200×200 투명) 디자인이 아직 없다.**
